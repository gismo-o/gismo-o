## ✦ About Me

I'm **Gizem**, a Computer Engineering graduate focused on **backend development and AI-powered applications**. I enjoy turning ideas into working applications and building the services and data flows that support them.

My projects bring together **C#/.NET, Java/Spring Boot, relational databases, and AI integrations**. I aim to develop practical backend solutions and integrate AI where it adds meaningful value to the user experience.

**Currently exploring:** API design · Database performance · LLM integration · RAG

I share technical notes and lessons from my projects on [Medium](https://medium.com/@gizemkoz).
